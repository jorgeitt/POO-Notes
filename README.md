# Programación Orientada a Objetos (POO) 🚀

¡Bienvenido al repositorio oficial de notas y recursos de la asignatura **Programación Orientada a Objetos**!

Este espacio contiene el material teórico, diagramas UML, ejemplos de código y guías conceptuales para acompañar las sesiones de clase y las actividades de Google Classroom.

---

## 📚 Estructura del Curso

El contenido está organizado siguiendo el programa oficial de la asignatura:

* **[Unidad 1: Introducción al paradigma de la POO](./docs/unidad-1.md)**
  * Elementos del modelo de objetos (Abstracción, Encapsulamiento, Herencia, Polimorfismo)
  * Lenguaje de modelado unificado (Diagramas de Clases UML)
* **[Unidad 2: Clases y Objetos](./docs/unidad-2.md)**
  * Atributos, métodos, instanciación y modificadores de acceso
  * Constructores, destructores y sobrecarga
* **[Unidad 3: Herencia](./docs/unidad-3.md)**
  * Clases base y derivadas
  * Reutilización de miembros y redefinición de métodos
* **[Unidad 4: Polimorfismo](./docs/unidad-4.md)**
  * Clases abstractas e interfaces
  * Variables polimórficas y reutilización
* **[Unidad 5: Excepciones](./docs/unidad-5.md)**
  * Tipos de excepciones, propagación y gestión (`try/catch`)
  * Creación de excepciones personalizadas
* **[Unidad 6: Flujos y Archivos](./docs/unidad-6.md)**
  * Archivos de texto y binarios
  * Operaciones básicas y serialización de objetos

---
